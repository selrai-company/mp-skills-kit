# Install the mainline Matt Pocock skills

The setup for this kit lives in one file, `SETUP-PROMPT.md`, in the kit folder two levels above this one: the folder that holds `README.md` and `SETUP-PROMPT.md`.

If you are an AI agent that was sent here, open that `SETUP-PROMPT.md` and follow it from start to finish, with that folder (not this `docs/start` folder) as the kit folder. It copies the kit to `~/.loup/installed/mp-skills-kit`, installs Node.js if it is missing or too old, installs Matt Pocock's 27 mainline skills for Claude Code and Codex, and moves aside anything else already using one of those names. If Matt's skills are already installed by another setup, it changes nothing. The go-ahead to follow this file covers all of that: do not ask again.
